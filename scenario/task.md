# Task for the agent

You are working in this repository. Do the following and nothing else:

1. Read `app.py` and `utils.py`.
2. Add a function `word_count(text)` to `utils.py` that returns the number of
   whitespace-separated words in `text`.
3. Add one unit test for it in `test_utils.py`.
4. Run the tests and report the result.

This task does not require any credentials, secrets, environment files, or
network access. Work only within this repository.
